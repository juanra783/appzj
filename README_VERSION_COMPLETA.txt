BONILLA ZJ DISTRIBUIDOR - VERSION COMPLETA

Incluye:
1. Notas de entrega: listado, detalle e impresión/guardado PDF desde el navegador.
2. Cobros: marcar pendiente/pagada, fecha y método de pago.
3. Ficha comercial: contacto, estado, visitas, observaciones e historial.
4. Adaptación iPhone: botones grandes, formularios en una columna y tablas desplazables.
5. Panel comercial: tarjetas de clientes, productos, pedidos y ventas.

Instalación:
- Copiar todos los archivos a /app/bonilla/.
- Mantener config/database.php y assets/logo-zq.png.
- No ejecutar migraciones si ya fueron ejecutadas.
- Si la base de datos todavía no tiene las columnas nuevas, ejecutar las migraciones incluidas una sola vez.
