BONILLA · ZJ DISTRIBUIDOR REPRESENTACIONES

Esta versión añade ficha comercial completa de clientes:
- Persona de contacto
- Estado comercial
- Última visita y próxima visita
- Observaciones
- Historial de pedidos
- Acceso directo para crear pedidos

Instalación:
1. Haz copia de seguridad de la base de datos.
2. Ejecuta migracion_precios.sql si aún no lo hiciste.
3. Ejecuta migracion_clientes.sql una sola vez.
4. Sube todos los archivos a /app/bonilla/.
5. Comprueba que existe assets/logo-zq.png.
