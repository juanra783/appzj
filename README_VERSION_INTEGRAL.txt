ZJ DISTRIBUIDOR REPRESENTACIONES - VERSION INTEGRAL

Incluye la base estable de clientes, productos, precios, pedidos, notas y cobros,
con logo principal ZJ Distribuidor, metadatos para compartir la dirección web, icono,
manifiesto PWA y adaptación móvil para iPhone.

IMPORTANTE:
- Haz copia de seguridad antes de sustituir archivos.
- Sube TODO el contenido de esta carpeta a /app/bonilla/.
- Conserva config/database.php con tus datos actuales.
- No ejecutes migraciones si ya fueron ejecutadas.
- Para que WhatsApp/Facebook actualicen la imagen de vista previa, la URL debe
  ser pública por HTTPS y puede ser necesario esperar a que sus sistemas la
  vuelvan a leer.
